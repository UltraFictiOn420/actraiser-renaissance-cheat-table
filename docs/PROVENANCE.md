# Provenance and redistribution

The archived original tables and development scripts were created during a user-led, AI-assisted single-player Cheat Engine project. Gameplay test results in the notes are user reports, not independent certification.

Existing third-party tables were supplied for reference in the World of Final Fantasy and Arkham City discussions. Their files are NOT redistributed here. Reference use must not be represented as proof that every technique, offset, or idea was independently discovered. Original archive filenames distinguish our generated tables from the reference tables.

Excluded: third-party .CT files, game executables and assets, full memory dumps, extracted game metadata/disassembly outputs, savegames, personal configuration backups, credentials, dependency packages, and temporary scan results.

No open-source license has been selected by the owner yet. An archive or public repository does not by itself grant redistribution rights to third-party reference material. Choose a license deliberately before advertising this as a licensed open-source project.

The known reference files were DrummerIX's World of Final Fantasy table and an older Batman Arkham City GOTY table whose author attribution has not yet been verified. Full third-party credits should be verified before public release.
